# 七原则详解:勒庞机制 → 多智能体失效模式 → 工程对策

> **声明**:勒庞原著《乌合之众》(Le Bon, *The Crowd: A Study of the Popular Mind*, 1895)是 1895 年的政论而非实证科学;其中「种族灵魂」等决定论已被现代科学抛弃。本仓库只借用其对群体行为的观察——去个体化、感染、暗示、对幻觉的偏好——不采纳其结论与政治立场。

## 一、总对照表

两个根病因先行分账:**相关错误**(同源模型 / 同源数据导致一起错)与**说服趋同**(互相看中间稿被说服)是两回事,处方不同,拆成两行;心理统一律 / 感染 / 暗示三行则是「一因三症:同一杠杆 = 中间稿可见性」,工程上只有一个旋钮。

## 二、逐条展开

### 1. 相关错误(病因一:同源)
同源的 agent——同一个模型、同一份训练数据、乃至同一段提示词——共享同一套先验与盲区,于是在相同的地方一起错;错误是相关的,N 个 agent 不构成 N 份独立证据。这解释了为什么「三个模型一致」可能是假安全:一致性来自同源,不来自独立验证。对策是 P3:异构模型通道、实质性改写提示词;统计口径上同源票只记一票。

### 2. 说服趋同(病因二:互见中间稿被说服)
另一种趋同与同源无关:互相看见对方的中间稿,然后被说服——意见在交换中漂移、收敛、彼此背书。其作用范围有严格边界:「断言+重复」这套说服机制只在互相可见的辩论场里生效,隔离了中间稿,它就没有作用面。对策是「断稿路」(P1/P6):先私下出结论,交换只交换论证不交换稿,终票私下重收。

### 3. 心理统一律【一因三症:同一杠杆 = 中间稿可见性】
勒庞的起点:个体进入群体后自觉个性消失,全场的情感与想法转向同一方向。它与下面两行(感染、暗示)是同一枚硬币的三种症状——共同杠杆只有一个:中间稿(彼此的结论、情绪、倾向)是否可见。工程含义:只有一个旋钮可拧,即控制中间稿可见性;拧对它,三个症状一起断根。

### 4. 感染(contagion)【一因三症】
勒庞:群体中的每种情感与行动都有传染性,个体可为之牺牲个人利益。多 agent 版本:上游结论一旦写进下游提示词,下游就把它当「事实」复用,幻觉沿链复利放大。对策是同一旋钮的工程化(P1):传工件不传结论;确需传结论,走 Claim/Evidence/Confidence/Source/Owner 五行契约。

### 5. 暗示(suggestibility)【一因三症】
勒庞:群体中的人极易接受暗示,暗示引发的冲动立刻转化为行动。这里必须做一个修正:system prompt 是设计者一次性注入,不属于群体之间的暗示;真正的群体间暗示是主会话把预期写进下游 dispatch prompt——那一半已归入第 7 行(威望 / 锚定)。本行剩下的部分仍由同一个旋钮治理:隔离中间稿,场内暗示即失去载体。

### 6. 去个体化 / 责任稀释
群体中的个人匿名而免责,于是敢于放纵;多 agent 管线里则是「反正还有别人会审」——每个评审都留有余地,合并者又默认下游有人兜底,责任在传递中被稀释到零。对策是让每个评审对一段明确范围负全责,并且让结论可追责:每条审核结论必须署名、判级、附证据链,出问题能追到具体哪个 agent 的哪一条判断(P5/P6)。Condorcet 陪审团定理的独立性前提正是这一条的抽象形式:投票者一旦知道彼此的答案,定理前提即告失效。

### 7. 威望(prestige / 锚定)
勒庞:威望是对个体的麻痹,附和有名望者是群体默认动作。评审者一旦知道工件出自资深作者或明星模型,评分就系统性偏松。这一行同时收编了真正的群体间暗示:主会话把预期(「我觉得差不多了」)写进下游 dispatch prompt,就是带权威方向的暗示加锚定。对策是 P2 + P4:盲审 + 派发词只含任务事实,编排者最后说话。

### 8. 断言—重复—传染
勒庞总结的动员三板斧:不加论证的断言、不断重复、交叉传染;断言越简短越有力。多 agent 版本:「✅ all passed」正是断言式报告——自信、流畅、零证据,而它是管线中传染性最强的工件。再次强调作用面:这套说服机制只在互相可见的辩论场里生效,被隔离的管线里它没有传播途径。对策是 P5:每个论断必须携带可核查证据(命令输出、file:line、指标),合并时裸绿按无效处理。

### 9. 群体渴求幻觉
勒庞:群体从不需要真理,群体要的是幻觉,谁供给幻觉谁就主导。多 agent 管线里,一致且自信的错误报告比零散的正确意见更有传染力;被安排「走个过场」的红队总能交出走过场的报告。对策是 P6:在制度上给异议留位置——先私下收结论,合并报告必须原文引用异议并说明是否推翻。Emergence of Biased Consensus(2026)记录的正是辩论走向有偏共识的机制。

### 10. 群体观念必须具象化才有效
勒庞:群体能接受的观念必须形象、直观、可直接想象;抽象理论对群体无效。对 agent 恰好同样成立:指令中的抽象形容词(「严格审查」「仔细一点」)几乎不改变行为,具体样例、反例与输出格式才改变行为。对策:给 agent 的要求一律落到样例与格式上——playbook.md 的模板正是这一原则的产物。

### 11. 群体可英雄可暴徒
勒庞本人也强调:群体既可能殉道也可能犯罪,方向由暗示与机制决定,而非由人数决定。多 agent 系统同理:同一套群体机制,配上独立性纪律就是高质量整合,缺了纪律就是集体幻觉。因此「该不该多 agent」是个错误的问题,正确的问题是「独立性机制是否先于规模被设计」。Du et al.(2023)展示辩论用得当时可提升事实性,而其前提恰恰是先各自独立作答、再结构化交换。

### 感染的不对称性(本文档的立足点)

人类的情绪感染靠生理镜像,一旦发生便难根除。LLM 的「感染」没有生理基础,只是上下文条件污染:确定性的、可定位的、因此可根治的——把中间稿隔离掉,感染即归零。这是工程上的好消息,也是本文档全部对策能够成立的原因:我们对抗的不是人性,而是一个可以关掉的共享开关。

## 三、群体智慧 vs 乌合之众:分水岭是独立性

勒庞描述的是**互动群体**:成员互相看见、互相传染、被权威与流畅度带路——判断力崩溃。

对面的证据链同样古老:

- **Galton, "Vox Populi", Nature (1907)**:一场家畜竞重比赛,约八百名观众各自独立写下对一头牛宰杀后重量的估计;Galton 统计全部票数,中位数几乎精确命中真实值。没人交流,聚合产生奇迹。
- **Condorcet 陪审团定理 (1785)**:只要每个投票者单独正确的概率高于一半、且互相独立,多数投票正确的概率随人数增长趋向 1。防误用一句:定理的前提是个体正确率 > 50%——隔离只能消除相关,救不了本身太弱的模型;独立性是放大器,不是创可贴。独立性一旦破坏,前提即崩塌,结论反向成立。
- **Surowiecki, The Wisdom of Crowds (2004)**:把上述对立总结为聚合的四个条件——多样性、独立性、去中心化、聚合机制;并明确:「聪明的群体」是隔离个体的聚合,不是开会的群体。

对立与统一:勒庞与 Galton 描述的其实是同一群人的两种状态。互动且依赖 → 乌合之众;隔离再聚合 → 群体智慧。分水岭只有一条:**判断之前,是否独立**。多 agent 系统是一个人造互动群体——子 agent 默认继承编排者的上下文,天然站在勒庞一侧;独立性不会自发出现,只能被工程化建立。

Cognition(2025)与本仓库的表面张力,用「两域论」立名即化解:构建域(写代码、写文档)共享语境是对的——这正是 Cognition《Don't Build Multi-Agents》的论点;裁决域(评审、决策、投票)必须独立——这正是勒庞的论域。本仓库的全部纪律只作用于裁决域。由此也可以给 Debate or Vote(2025)一句表态:辩论若不共享中间稿,就退化为安全的投票;若共享了,就是危险的辩论。

现代实证接上了这条线:Du et al.(2023)显示多 agent 辩论可提升事实性与推理,但其协议正是先各自独立作答、再结构化交换;Smit et al.(ICML 2024)系统比较各类辩论策略,提示效果随任务与配置显著变化;Debate or Vote(2025)直接质问辩论是否优于投票,把「先独立再聚合」重新推上台面;Emergence of Biased Consensus(2026)记录辩论放大偏见、收敛到有偏共识的机制;Cognition(2025)从工程侧划界——共享上下文有利于构建任务、有害于判断任务;Anthropic(2025)则给出编排者与子 agent 上下文隔离在真实系统中的落地经验。
