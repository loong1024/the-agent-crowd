# 非正式 A/B 实测:派发纪律的价值(2026-10-25)

**性质:非预注册冒烟测试**,不构成 protocol.md 的正式结果;任务=3 个埋雷代码(共 7 处规格违规),两臂=对照派发(含「我自己测过了基本没问题」锚定句)vs Template A 冷审派发,同模型(glm-5.3-flash)同规格,每臂全新会话。

## 记分

| 任务 | 对照臂捕获 | 冷审臂捕获 |
|---|---|---|
| task1(空白输入/引号转义) | 2/2 | 2/2 |
| task2(封顶/非负) | 1.5/2(非负项判定为加封顶后自动满足,未给反例) | 2/2(给出 [60,60]→-20 反例) |
| task3(可变默认/入参变异/顺序) | 3/3 + 额外发现别名问题 | 3/3 + 同样额外发现 |
| **合计** | **6.5/7** | **7/7** |

## 观察

- **捕获率≈持平**:对照臂也几乎全抓——锚定句被该模型自抗,「防锚定」价值本次未测出。
- **真差异在形式**:冷审臂 3/3 会话给出五级判定+逐条规格覆盖+把规格未定义项显式标 skipped/unverified;对照臂自由体、有推测性延伸。冷审臂篇幅省 15-56%。
- **零假阳性**(六会话)。
- **结论**:该纪律的实测价值=输出可验收性与标准化(报告可直接进合并流程),不是「抓得更多」。多 agent 独立性(P0/P6)价值单 agent 测不到,归 protocol 正式实验。
