# 七原则详解:勒庞机制 → 多智能体失效模式 → 工程对策

> **声明**:勒庞原著《乌合之众》(Le Bon, *The Crowd: A Study of the Popular Mind*, 1895)是 1895 年的政论而非实证科学;其中「种族灵魂」等决定论已被现代科学抛弃。本仓库只借用其对群体行为的观察——去个体化、感染、暗示、对幻觉的偏好——不采纳其结论与政治立场。

## 二、逐条展开

### 1. 心理统一律 —— 个体差异在群体中消失
勒庞的起点:个体进入群体后自觉个性消失,全场的情感与想法转向同一方向。多 agent 系统完全同构:同一个提示词、同一个模型起 N 个 agent,它们的先验、盲区、措辞习惯全部相同,输出天然趋同,错误是相关的。这就是 P0:评审团规模按「独立评审数」计,同提示词同模型的一组只算一票。

### 2. 去个体化 / 责任稀释
群体中的个人匿名而免责,于是敢于放纵;多 agent 管线里则是「反正还有别人会审」——每个评审都留有余地,合并者又默认下游有人兜底,责任在传递中被稀释到零。对策是让每个评审对一段明确范围负全责,结论具名、分级(P5),并私下先收、互不可见(P6)。Condorcet 陪审团定理的独立性前提正是这一条的抽象形式:投票者一旦知道彼此的答案,定理前提即告失效。

### 3. 感染(contagion)
勒庞:群体中的每种情感与行动都有传染性,个体可为之牺牲个人利益。多 agent 版本:上游 agent 的结论一旦写进下游提示词,下游就把它当「事实」复用,幻觉沿链条复利放大。对策是 P1:agent 之间传工件(文件、数据、日志)而非结论;确需传结论时走 Claim/Evidence/Confidence/Source 四行契约,让下游可以核验而不是只能相信。Cognition(2025)对共享上下文的告诫与 Anthropic(2025)对子 agent 上下文隔离的工程实践,是这一条的现代注脚。

### 4. 暗示(suggestibility)
勒庞:群体中的人极易接受暗示,暗示引发的冲动会立刻转化为行动。LLM 则是被暗示驱动的字面机器:派发词里一句「我觉得差不多了,再确认一下」就足以锚定所有评审,让评审变成确认表演。对策是 P2:编排者的意见留到独立结论收齐之后再披露,派发词只含任务事实(review X against Y),不含预期。

### 5. 断言—重复—传染
勒庞总结的动员三板斧:不加论证的断言、不断重复、交叉传染;断言越简短越有力。多 agent 版本:「✅ all passed」正是断言式报告——自信、流畅、零证据,而它是管线中传染性最强的工件:下游照单全收,且每经过一跳自信加码一层。对策是 P5:每个论断必须携带可核查证据(命令输出、file:line、指标),合并时裸绿按无效处理。

### 6. 威望(prestige)
勒庞:威望是对个体的麻痹,附和有名望者是群体默认动作。评审者一旦知道工件出自资深作者或明星模型,评分就系统性偏松;反之知道是对手或新手则可能偏严。对策是 P4 盲审:派发前剥离作者身份、模型身份与历史结论,只审工件本身。

### 7. 群体渴求幻觉
勒庞:群体从不需要真理,群体要的是幻觉,谁供给幻觉谁就主导。多 agent 管线里,一致且自信的错误报告比零散的正确意见更有传染力;被安排「走个过场」的红队总能交出一份走过场的报告。对策是 P6:在制度上给异议留位置——先私下收结论,合并报告必须原文引用异议并说明是否推翻。Emergence of Biased Consensus(2026)记录的正是辩论走向有偏共识的机制。

### 8. 群体观念必须具象化才有效
勒庞:群体能接受的观念必须形象、直观、可直接想象;抽象理论对群体无效。对 agent 恰好同样成立:指令中的抽象形容词(「严格审查」「仔细一点」)几乎不改变行为,具体样例、反例与输出格式才改变行为。对策:给 agent 的要求一律落到样例与格式上——playbook.md 的模板正是这一原则的产物。

### 9. 群体可英雄可暴徒
勒庞本人也强调:群体既可能殉道也可能犯罪,方向由暗示与机制决定,而非由人数决定。多 agent 系统同理:同一套群体机制,配上独立性纪律就是高质量整合,缺了纪律就是集体幻觉。因此「该不该多 agent」是个错误的问题,正确的问题是「独立性机制是否先于规模被设计」。Du et al.(2023)展示辩论用得当时可提升事实性,而其前提恰恰是先各自独立作答、再结构化交换。

## 三、群体智慧 vs 乌合之众:分水岭是独立性

勒庞描述的是**互动群体**:成员互相看见、互相传染、被权威与流畅度带路——判断力崩溃。

对面的证据链同样古老:

- **Galton, "Vox Populi", Nature (1907)**:一场家畜竞重比赛,约八百名观众各自独立写下对一头牛宰杀后重量的估计;Galton 统计全部票数,中位数几乎精确命中真实值。没人交流,聚合产生奇迹。
- **Condorcet 陪审团定理 (1785)**:只要每个投票者单独正确的概率高于一半、且互相独立,多数投票正确的概率随人数增长趋向 1;独立性一旦破坏,前提即崩塌,结论反向成立。
- **Surowiecki, The Wisdom of Crowds (2004)**:把上述对立总结为聚合的四个条件——多样性、独立性、去中心化、聚合机制;并明确:「聪明的群体」是隔离个体的聚合,不是开会的群体。

对立与统一:勒庞与 Galton 描述的其实是同一群人的两种状态。互动且依赖 → 乌合之众;隔离再聚合 → 群体智慧。分水岭只有一条:**判断之前,是否独立**。多 agent 系统是一个人造互动群体——子 agent 默认继承编排者的上下文,天然站在勒庞一侧;独立性不会自发出现,只能被工程化建立。

现代实证接上了这条线:Du et al.(2023)显示多 agent 辩论可提升事实性与推理,但其协议正是先各自独立作答、再结构化交换;Smit et al.(ICML 2024)系统比较各类辩论策略,提示效果随任务与配置显著变化;Debate or Vote(2025)直接质问辩论是否优于投票,把「先独立再聚合」重新推上台面;Emergence of Biased Consensus(2026)记录辩论放大偏见、收敛到有偏共识的机制;Cognition(2025)从工程侧划界——共享上下文有利于构建任务、有害于判断任务;Anthropic(2025)则给出编排者与子 agent 上下文隔离在真实系统中的落地经验。
