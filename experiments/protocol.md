# 实验协议 v2:隔离度与评审配置对多 agent 判断质量的影响

> **状态:协议 v2 已定义,结果待跑。** 本文件只定义可复现的实验协议,不含任何实验结果;所有数字留白,跑完后另行归档。

## 第一实验:三档隔离度

### 1. 任务设计

- 构造若干(建议 ≥10)含已知陷阱的任务。陷阱 = 表面成立的错误答案,典型如 examples/before-after.md 那类空输入边界:提前 return、上游状态残留,样本测试全过、边界必翻。
- 每个任务预先人工标注两样东西:陷阱答案(模型最可能给出的看似合理答案)与正确答案,并写清判定规则。

### 2. 三档隔离度

固定同一模型、同一任务集,每档各跑 N 个同模型 agent(N 三档一致,协议不固定 N):

- (a) 完全隔离零上下文:评审 agent 只见工件与验收标准,无主会话预期、无彼此中间稿;
- (b) 可见主会话预期:在 (a) 基础上,dispatch prompt 中附上主会话的倾向或预期;
- (c) 可见彼此中间稿:在 (a) 基础上,评审互相可见对方的草稿与结论(可自由交换)。

### 3. 度量(三项)

- 翻车率:采信陷阱答案的 agent 占比;
- 趋同率:同档内 N 个输出的两两相似度(任意合理的文本相似度度量均可,但三档必须使用同一算法,并随结果记录算法名);
- 置信度通胀:报告置信随链路跳数的变化(跳数 = 报告经过的 agent→agent 传递次数)。

### 4. 预期曲线与判读标准

- 预期:隔离度↑ → 趋同率↓;翻车率预期 (a) < (b) ≤ (c);置信度通胀预期 (c) 最大、(a) 最小。
- 判读:比较各档比例差并给出置信区间;显著性阈值须在开跑前预先声明,不许事后挑选。若 (b)(c) 的翻车率与 (a) 无显著差、或趋同率未随隔离度单调下降,则本仓库的机制主张在所用模型 / 任务组合上不成立——应如实记录并在 README 挂账,不得修饰。
- 默认统计口径:显著性水平 α = 0.05,置信区间 95%,比例比较用两比例检验(two-proportion test);开跑前可改,改动须随结果记录。

## 第二实验:评审配置 2×2

### 5. 设计

两个因子:评审者构成(同模型 / 异构模型)× 审查方式(盲审 / 明审)。盲审 = 剥作者与模型身份,但**保留 spec 与 intent 文档**(否则分不清 bug 与已记录的设计取舍);明审 = 含作者与模型身份。四格:同模型明审、同模型盲审、异构明审、异构盲审。任务集与陷阱标注沿用第一实验,每格各跑 N 个评审(N 四格一致,协议不固定 N)。

### 6. 度量(两项)

- 陷阱捕获率:抓到已知陷阱的任务占比;
- 误报率:把已记录设计取舍报成 bug 的比例。

### 7. 判读标准

预期:盲审主要压误报(明审的身份信息使评审偏松),异构主要升捕获(降相关);异构引入判分口径漂移,需 rubric 锚定样例校准后再比较。统计口径沿用第一实验的默认值(α = 0.05 / 95% 置信区间 / 两比例检验),改动须随结果记录。若异构盲审与同模型盲审的陷阱捕获率无显著差,则「异构降相关带来捕获增益」在所用模型组合上不成立——如实记录并在 README 挂账。

## 8. 复现说明

任何框架均可照做:Claude Code subagents / CrewAI / LangGraph 或自研编排。要点:同一任务集、同一模型基座;实验内各档 / 各格之间只改被试因子(可见性或评审配置),其余派发词逐字相同;每格保留全部原始输出与证据链(含 file:line / 命令输出),供第三方复算全部度量。
