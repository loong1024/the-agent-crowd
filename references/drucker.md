# 德鲁克组织工程学:把各自平庸的个体,组织成产出成果的系统

> **定位**:勒庞是失效叙事——判断如何坏掉;德鲁克是建设叙事——如何把各自平庸的个体组织成产出成果的系统。勒庞的处方要降级为隐喻才能用;德鲁克的处方是组织工程观察,经一次翻译即可用;映射有效性属设计类比,待实验实测。

> **范围声明**:本文件的管理学处方映射到 agent 体系属**设计类比而非实测结论**(与 P5 证据纪律一致);可实测的部分见 experiments/protocol.md。

> **书目纪律**:本文件只引用文末清单所列德鲁克著作与年份,不另引其他文献。

## D1 MBO 目标管理与自我控制 →「目标派发制」(《管理的实践》1954)

**德鲁克原意**:控制的主体必须是被管理者本人,而不是上级;上级给目标与标准,不给操作步骤。

**配套警告**:「报告与程序是工具,应保持最小量」——它们不足时是失控,过度时组织瘫痪。

**agent 翻译**:dispatch 三件套 = 目标陈述 + 成功标准 + 可自查度量,不给步骤指令。控制主体是执行 agent 本人:它拿到的是「什么算完成」,不是「每一步怎么走」;步骤指令只出现在不需要判断的环节。

**落地规则**:三件套缺一不派;报告与程序最小化——小交付口头置信 + 抽查即可(playbook 豁免规则的管理学出处);完整模板见 playbook.md Template E。

## D2 知识工作者生产率六因素 → agent 生产率纲领(《21世纪的管理挑战》1999)

**德鲁克原意**:知识工作者的生产率取决于六个因素,逐条映射如下:

| # | 德鲁克因素 | agent 翻译 |
|---|---|---|
| 1 | 先定义任务:质量是什么、客户付钱买什么 | 派发前先答「这个交付物的好坏标准是什么」;答不出不派 |
| 2 | 知识工作者必须自主管理 | 目标制不步骤制(承接 D1) |
| 3 | 创新是工作的组成部分 | 允许 agent 对流程本身提改进意见,不只当执行器 |
| 4 | 持续学习与教学 | prompt 迭代、记忆库、案例回流。注:经验沉淀由编排者承担,agent 自身不学习——这是与人类知识工作者的关键不对称 |
| 5 | 质量不是数量的下限约束,而是产出的本质,至少与数量同等重要(质量与数量是同一件事) | 判级分级,不数数量:pass/fail/blocked/skipped/unverified,不报「改了 20 处」 |
| 6 | 知识工作者是资产非成本 | 配置(上下文 / 工具 / 样例)是资产;一次性用完即弃更贵 |

## D3 有效决策规矩 → orchestrator 决策程序(《卓有成效的管理者》1966)

**德鲁克原意**:有效的决策者不追求多决策,追求决策正确。四条规矩:

- **无异议不决策**:没有反对意见就不做决策。与 P6 是同一杠杆的双向:P6 保全异议存活,D3 把异议缺失本身当作报警信号——机制互补,不是同一件事。

- **先定边界条件**:拍板前先写「什么情况下这个决策会错」;过不了边界条件检验的决定不配叫决策。

- **失败保护**:德鲁克对人事决策的观察是约三分之一做对;决策须默认相当比例会错,必须带退出路径。

- **决策必须转化为行动**:不落为派发与行动的决策只是偏好。

## D4 联邦分权制 → agent 编队(《公司的概念》1946;《管理:任务、责任、实践》1973)

**德鲁克原意**:联邦制中央只管政策,单位对成果负全责;结构跟随使命(德鲁克原话关注成果与贡献;结构跟随战略是钱德勒的命题,此处属化用);检验标准是各单位是否真为成果负责。

**agent 翻译**:中央(编排者)只管政策——交接契约、接口、红线、判级标准;编队围绕交付物组织,不围绕职能组织;每个编队对自己的成果负全责(署名 + 判级 + 证据链)。

**落地规则**:派发以交付物为单位切分;自检一个问题:「这个编队里有没有人能独立回答『活干完了吗』」——答不出,就是围绕职能而不是围绕使命编的队。

## D5 信息型组织 → 无中间层 agent 群(1988「The Coming of the New Organization」)

**德鲁克原意**:信息革命让信息直达决策者,中间管理层从转述层变成累赘;组织像乐队——指挥仍持全谱定拍,德鲁克砍的是中间转述层:乐手各司其职、信息直达,无需层层中继;乐谱是共同标准;成员关系是伙伴,不是命令链。

**agent 翻译**:裁掉中间层转述 agent——任何只做「把 A 的话转给 B」的 agent 都该被直接管道替代。

**落地规则**:乐谱 = 交接契约 + 判级标准,大家照同一份谱子演奏,不需要看指挥的脸;agent 之间是伙伴契约,不是上下级命令。

## 第二梯队(简表)

| 德鲁克工具 | 出处 | agent 翻译 |
|---|---|---|
| 反馈分析法:行动前写预期,事后对照 | 《自我管理》1999 | 预注册预期:派发前写下预期结论,跑完对照(与 protocol.md 预声明规则同构) |
| 优势用人:只问「能做什么」 | 《卓有成效的管理者》1966 | 模型按优势分派:快的做广度、强的做深度;不造「平均全能 prompt」 |
| 组织的目的:让平凡人做不平凡事 | 《管理的实践》1954 | 不指望英雄 agent;结构把过线(>50%)的个体放大为集体成果;过线以下,隔离也救不了 |
| 绩效精神:诚信高于聪明 | 《管理的实践》(1954) | 一致地按证据办事,优先于展示聪明 |
| 管理者五大运营:定目标 / 组织 / 沟通 / 度量 / 发展人 | 《管理的实践》1954 | 发展人 = 迭代 prompt、积累案例、升级工具 |

## 不适用或反着用

- 「文化吃掉战略早餐」:非德鲁克原话,流传误归;agent 无文化,替代物是共享协议。

- 「被度量才被管理」:非其原文;真实主张是无度量则无自我控制——度量服务自我控制,不是向上汇报。

- 蓝领满意度与激励模型:其晚年自认失败;agent 无满意度,跳过。

- 命令链层级:已被他自己的信息型组织论证淘汰,不引入。

## 与本仓库防御框架的关系

勒庞侧是防御:裁决域隔离(P1 / P2 / P6),防判断变坏。

德鲁克侧是建设:MBO 目标派发(D1)、联邦编队(D4)、共同乐谱(D5),让产出变好。

合并总纲一句话:**防御靠隔离,建设靠目标、联邦与乐谱。**
